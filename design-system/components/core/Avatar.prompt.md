User or student identity — image with initials fallback.

```jsx
<Avatar name="Maya Rodriguez" />
<Avatar src="/photo.jpg" name="Maya Rodriguez" size="lg" />
<AvatarGroup>
  <Avatar name="A B" size="sm" />
  <Avatar name="C D" size="sm" />
</AvatarGroup>
```

Sizes `sm | md | lg`; `square` for rounded-rect.
