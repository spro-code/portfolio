The opening of any story section — mono eyebrow, serif title (with optional `<em>` italic), and a lead.

```jsx
<SectionHeader
  eyebrow="03 — Insight"
  title="Teachers don't need more data. They need to <em>see what it means.</em>"
  lead="The opportunity wasn't another dashboard — it was a clearer line of sight."
/>
```

`center` centers it; `title` accepts an HTML string for italic emphasis.
